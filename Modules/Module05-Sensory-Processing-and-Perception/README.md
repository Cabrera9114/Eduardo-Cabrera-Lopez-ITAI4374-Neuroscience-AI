## Key Concepts Learned

One of the most important concepts I learned in this module was that perception is not passive. The brain does not simply receive sensory data like a camera recording the world. Instead, the brain actively constructs reality using sensory input, predictions, prior knowledge, and contextual information. :contentReference[oaicite:1]{index=1}

The module explained the difference between sensation and perception:

- Sensation = raw physical signal transduction
- Perception = the brain’s interpretation of sensory information

This distinction demonstrated how biological intelligence continuously predicts and reconstructs the world from incomplete sensory data. :contentReference[oaicite:2]{index=2}

Another major concept was the inverse problem in perception. The brain receives incomplete sensory signals and must infer the most likely interpretation of reality using prior expectations and predictive processing mechanisms. :contentReference[oaicite:3]{index=3}

## Visual Processing and CNN Inspiration

One of the most interesting sections of this module focused on the visual cortex hierarchy and its relationship to CNN architecture.

I learned how:
- retinal ganglion cells detect edges and contrast
- center-surround receptive fields inspired edge detection filters
- hierarchical visual processing inspired deep convolutional networks
- retinotopic mapping influenced convolutional architectures
- event-based vision systems mimic biological retinas

The module explained how CNNs independently learn filters similar to biological center-surround receptive fields found in the retina. :contentReference[oaicite:6]{index=6}

The relationship between neuroscience experiments by Hubel and Wiesel and modern CNN architectures showed how deeply neuroscience has influenced AI perception systems.

## Predictive Processing

The predictive processing research introduced the idea that the brain continuously generates predictions about incoming sensory information.

Instead of passively receiving sensory input, the brain:
- predicts sensory data
- compares predictions with actual input
- generates prediction errors
- updates internal world models

This concept strongly connects with:
- predictive coding
- generative AI
- diffusion models
- reinforcement learning
- active inference systems

:contentReference[oaicite:7]{index=7}

The concept of active inference was especially interesting because it unified perception and action into one prediction-based computational framework.
