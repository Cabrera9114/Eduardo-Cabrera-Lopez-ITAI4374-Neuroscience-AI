## Key Concepts Learned

One of the main concepts I learned in this module was how the brain is organized into specialized regions that work together to process information. The frontal, parietal, temporal, and occipital lobes each perform different functions such as decision-making, memory, language, and vision.

I also learned how subcortical structures like the hippocampus, amygdala, thalamus, and basal ganglia contribute to memory, emotion, attention, and reinforcement learning. The connection between dopamine systems and temporal difference learning in reinforcement learning was especially interesting because it demonstrated how biology inspired modern AI algorithms.

Another major topic was computational neuroscience, which focuses on mathematically modeling how neurons and neural systems process information. I studied neuron anatomy including dendrites, soma, axons, and synapses, along with action potentials and spike generation.

The Leaky Integrate-and-Fire (LIF) model introduced how biological neurons can be represented mathematically through membrane voltage accumulation and threshold firing behavior.

## Biological vs Artificial Neural Networks

This module explored major differences between biological neurons and artificial neural networks.

### Biological Neurons
- Communicate using electrochemical spikes
- Operate through time-dependent dynamics
- Learn through synaptic plasticity
- Extremely energy efficient (~20 watts)
- Distributed and adaptive

### Artificial Neural Networks
- Use mathematical weighted sums
- Rely on backpropagation
- Require significant computational resources
- Process continuous numerical values
- Optimized for specific tasks
