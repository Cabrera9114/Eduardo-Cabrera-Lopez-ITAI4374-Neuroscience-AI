## Working Memory and AI Context Windows

I learned that working memory functions as the brain’s temporary scratchpad, allowing humans to hold and manipulate information in real time. The module explained how the prefrontal cortex maintains sustained neural firing to temporarily preserve information. :contentReference[oaicite:2]{index=2}

The AI comparison was especially interesting because it connected biological working memory with:
- context windows in large language models
- hidden states in recurrent neural networks
- CPU register systems

The module also explained an important limitation in current AI systems:
AI working memory is usually fixed in size, while biological working memory dynamically adapts depending on attention and task difficulty. :contentReference[oaicite:3]{index=3}

## Episodic Memory and the Hippocampus

The module explored episodic memory using the famous neuroscience case of Henry Molaison (H.M.), whose hippocampus was removed to treat epilepsy. :contentReference[oaicite:4]{index=4}

This case demonstrated that:
- the hippocampus is critical for forming new episodic memories
- memory systems can function independently
- procedural learning can remain intact even when episodic memory is damaged

The hippocampus was described as a memory indexing and binding system that connects distributed sensory and emotional representations into unified experiences. :contentReference[oaicite:5]{index=5}

This directly inspired several AI concepts:
- Retrieval-Augmented Generation (RAG)
- replay buffers
- memory-augmented neural networks
- episodic reinforcement learning systems

## Memory Consolidation and Sleep

One of the most interesting concepts was hippocampal replay during sleep.

The module explained that:
- the hippocampus temporarily stores experiences
- during sleep, experiences are replayed
- replay strengthens cortical memory connections
- replay helps prevent catastrophic forgetting

This biological replay process directly inspired:
- experience replay buffers in Deep Q Networks (DQN)
- replay-based reinforcement learning systems
- memory stabilization techniques in AI

:contentReference[oaicite:8]{index=8}

I found it fascinating that DeepMind reinforcement learning architectures were partially inspired by hippocampal replay systems found in neuroscience.

## Reconstructive Memory

Another major concept was that biological memory is reconstructive rather than perfectly stored like a video recording.

The module explained that:
- memories are rebuilt during recall
- memories can change over time
- recall introduces distortions
- memory reconstruction enables flexibility

This created an interesting contrast with AI systems:
- AI often has exact recall
- biological systems trade accuracy for adaptability and flexibility
