## Lab Summary – Cortical Column Voting Simulation

In this lab, I implemented a simplified cortical column voting simulation inspired by Jeff Hawkins’ Thousand Brains Theory.

The simulation demonstrated:
- Multiple cortical columns receiving partial sensory information
- Distributed processing
- Consensus formation through voting
- Communication between columns
- Emergent agreement over time

The project helped connect neuroscience theories with practical AI implementation using Python and Jupyter Notebook.

---

## What I Learned

One of the most important concepts I learned in this module was that the brain does not passively receive reality. Instead, it actively constructs internal models of the world based on sensory input and prediction.

I learned about the difference between sensation and perception and how the brain continuously updates predictions using incoming information. This idea connects closely to predictive coding and modern AI architectures.

Another major concept was the Thousand Brains Theory, which proposes that intelligence emerges from many cortical columns independently building models of the world and communicating through voting mechanisms.

The lab simulation helped me better understand how distributed intelligence and consensus systems work in both neuroscience and AI.

I also learned how neuroscience fields such as computational neuroscience and cognitive neuroscience directly influence modern AI research.
